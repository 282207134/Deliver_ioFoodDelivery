## 分类与入口

| 范围 | 页面类别 | 正常操作入口 |
| --- | --- | --- |
| 01–06 | 登录、注册、区号、短信与错误 | 首次打开 → 手机登录 / Sign Up |
| 07–09 | 三步引导 | 验证码 1234 → Continue |
| 10–13 | 首页、附近餐厅、完整首页、热门 | Home → 地址 / See more |
| 14–20 | 空订单、历史、待结算、配送、评价 | Cart → Active / History → Track order；Profile → Rate Us |
| 21–26 | 通知、空卡、有卡、编辑、加卡、扫描 | Profile → Notifications / Payment method |
| 27–29 | 个人资料、输入、改号验证 | Profile → Profile information → Save |
| 30–32 | 地址列表、邀请、地址信息 | Profile → Address / Refer to friends |
| 33–36 | 餐厅、菜品、支付成功和失败 | Home → 餐厅 → 菜品；Cart → 结算 |
| 37–40 | 搜索餐厅、菜品、搜索输入和结果 | Search 标签 / 首页搜索栏 |
| 41–45 | 账户、购物车、结算 | Profile / Cart |
| 46–50 | 地址查询、地图、地址与支付选择 | 首页 Deliver to；结算页地址/支付方式 |
| 51 | 启动 | 启动 App |

原稿中的登录、商品、购物车、支付、评价和地址变更包含不同弹层表达。实现使用 Flutter 页面/底部对齐面板，保留相应层次与交互，部分表单以整页呈现以便键盘和小屏适配。FAQ 与新增地址表单为补全流程的附加页面。
